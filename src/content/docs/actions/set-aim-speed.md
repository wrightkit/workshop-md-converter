## Description

<big>Sets the aim speed of one or more players to a percentage of their normal aim speed.</big>

## Snippet

```
Set Aim Speed(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Turn Speed Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose aim speed will be set.

> ==**Turn Speed Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The percentage of normal aim speed to which the player or players will set their aim speed.
