---
title: "Set Match Time"
---

## Description

<big>Sets the current match time (which is visible at the top of the screen). This can be used to shorten or extend the duration of a match or to change the duration of assemble heroes or setup.</big>

## Snippet

```
Set Match Time(0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Time_==

> ==**Time**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The match time in seconds.
