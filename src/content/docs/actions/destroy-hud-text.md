---
title: "Destroy HUD Text"
---

## Description

Destroys HUD text that was created by Create HUD Text.

## Snippet

```
Destroy HUD Text(Last Text ID);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Text ID_==

> ==**Text ID**==
> _Type: **Text ID**, Default: **[Last Text ID](/values/last-text-id/)**_
> Specifies which hud text to destroy. This id may be last text id or a variable into which last text id was earlier stored.
