## Description

<big>Sets the healing dealt of one or more players to a percentage of their raw healing dealt.</big>

## Snippet

```
Set Healing Dealt(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Healing Dealt Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose healing dealt will be set.

> ==**Healing Dealt Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
>
