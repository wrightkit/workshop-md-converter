---
title: "Enable Built-In Game Mode Respawning"
---

## Description

Undoes the effect of the Disable Built-In Game Mode Respawning action for one or more players.

## Snippet

```
Enable Built-In Game Mode Respawning(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_PlayerS_==

> ==**PlayerS**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose respawning is affected.
