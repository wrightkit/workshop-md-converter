Cancels the behavior of Start Forcing Dummy Bot Name for the specified Player or Players.

## Snippet

```
Stop Forcing Dummy Bot Name(Event Player);
```

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
