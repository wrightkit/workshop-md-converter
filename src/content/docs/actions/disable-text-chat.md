---
title: "Disable Text Chat"
---

## Description

<big>Disables Text Chat for one or more Players until reenabled.</big>

## Snippet

```
Disable Text Chat(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The Player or Players who will have their Text Chat disabled.
