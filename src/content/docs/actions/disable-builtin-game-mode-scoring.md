---
title: "Disable Built-In Game Mode Scoring"
---

## Description

<big>Disables changes to player and team scores from the game mode itself, only allowing scores to be changed by scripting commands.</big>

## Snippet

```
Disable Built-In Game Mode Scoring;
```
