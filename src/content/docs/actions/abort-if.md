---
title: "Abort If"
---

## Description

<big>Stops execution of the action list if this action's condition evaluates to true. If it does not, execution continues with the next action.</big>

## Snippet

```
Abort If(True);
```


## Basic explanation
If the given condition is true, then stop whatever this current set of instructions is doing.

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Condition_==

> ==**Condition**==
> _Type: **Boolean**, Default: **[Compare](/values/compare/)**_
> Specifies whether the execution is stopped.
