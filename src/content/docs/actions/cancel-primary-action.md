---
title: "Cancel Primary Action"
---

## Description

<big>Cancels the active abilities for one or more players. Equivalent to a short stun.</big>

## Snippet

```
Cancel Primary Action(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players to cancel active abilities for.
