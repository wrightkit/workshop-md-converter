## Description

<big>Sets the score for one or both teams. This action has no effect in free-for-all modes or modes without a team score.</big>

## Snippet

```
Set Team Score(Team(Team 1), 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Team_==, ==_Score_==

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team or teams whose score will be set.

> ==**Score**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The score that will be set.
