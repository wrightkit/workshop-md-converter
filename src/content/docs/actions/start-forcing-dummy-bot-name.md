title: "Start Forcing Dummy Bot Name"
---

## Description

Starts forcing the name for the specified Player or Players.
Make sure the dummy bot has had time to spawn before giving them their name.

## Snippet

```
Start Forcing Dummy Bot Name(Event Player, Custom String(""));
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Name_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The Player whose name will be forced.

> ==**Name**==
> _Type: **String**, Default: **Custom String("")**_
> The name to be forced.
