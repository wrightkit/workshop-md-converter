## Description

<big>Sets the move speed of one or more players to a percentage of their raw move speed.</big>

## Snippet

```
Set Move Speed(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Move Speed Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose move speed will be set.

> ==**Move Speed Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The percentage of raw move speed to which the player or players will set their move speed.
