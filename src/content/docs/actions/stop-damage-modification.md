---
title: "Stop Damage Modification"
---

## Description

Stops a damage modification that was started by the Start Damage Modification action.

## Snippet

```
Stop Damage Modification(Last Damage Modification ID);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Damage Modification_==

> ==**Damage Modification**==
> _Type: **DamageModificationId**, Default: **[Last Damage Modification ID](/values/last-damage-modification-id/)**_
> Specifies which damage modification instance to stop. This id may be last damage modification id or a variable into which last damage modification id was earlier stored.
