## Description

<big>Sets the projectile speed for one or more players to a percentage of projectile speed.</big>

## Snippet

```
Set Projectile Speed(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Projectile Speed Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose projectile speed will be set.

> ==**Projectile Speed Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The percentage of regular projectile speed to which the player or players will set their personal projectile speed.
