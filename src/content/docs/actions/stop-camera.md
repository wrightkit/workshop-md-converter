## Description

<big>Restores the camera to the default view.</big>

## Snippet

```
Stop Camera(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose cameras will be put back to the default view.
