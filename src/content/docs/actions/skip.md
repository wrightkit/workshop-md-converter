## Description

<big>Skips execution of a certain number of actions in the action list.</big>

## Snippet

```
Skip(0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Number OF Actions_==

> ==**Number OF Actions**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The number of actions to skip, not including this action.
