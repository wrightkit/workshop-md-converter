---
title: "Disable Death Spectate All Players"
---

## Description

Undoes the effect of the Enable Death Spectate All Players action for or more players.

## Snippet

```
Disable Death Spectate All Players(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose default death spectate behavior is restored.
