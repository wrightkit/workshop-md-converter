## Description

<big>Disables the Game Mode In-World UI for one or more Players until reenabled.</big>

## Snippet

```
Disable Game Mode In-World UI(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The Player or Players who will have their Game Mode In-World UI disabled.
