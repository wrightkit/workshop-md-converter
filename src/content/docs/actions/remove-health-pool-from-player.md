---
title: "Remove Health Pool From Player"
---

## Description

Removes a health pool that was added via the Add Health Pool action.

## Snippet

```
Remove Health Pool From Player(Last Created Health Pool);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Health Pool ID_==

> ==**Health Pool ID**==
> _Type: **Integer**, Default: **[Last Created Health Pool](/values/last-created-health-pool/)**_
> Specifies a Health Pool created by the Add Health Pool action. (Health pool IDs may be obtained using the Last Created Health Pool Value.)
