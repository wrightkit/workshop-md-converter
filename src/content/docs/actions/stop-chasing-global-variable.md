## Description

<big>Stops an in-progress chase of a global variable, leaving it at its current value.</big>

## Snippet

```
Stop Chasing Global Variable(variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Variable_==

> ==**Variable**==
> _Type: **Global Variable**, Default: **A**_
> Specifies which global variable to stop modifying.
