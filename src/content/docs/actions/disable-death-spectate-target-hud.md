---
title: "Disable Death Spectate Target HUD"
---

## Description

Undoes the effect of the Enable Death Spectate Target HUD action for or more players.

## Snippet

```
Disable Death Spectate Target HUD(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players who will revert to seeing their own hud while death spectating.
