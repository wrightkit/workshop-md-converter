---
title: "Break"
---

## Description

Denotes an action that will abort execution of the current [While](/actions/while/) or For loop. Execution jumps to the next action after the [End](/actions/end/) Action.

## Snippet

```
Break;
```

## Basic explanation

Break: Stop this specific loop you're currently in right now, but continue with the rest of the instructions that come after the loop.

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: _None_
