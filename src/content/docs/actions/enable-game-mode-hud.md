---
title: "Enable Game Mode HUD"
---

## Description

Undoes the effect of the Disable Game Mode HUD action for one or more Players.

## Snippet

```
Enable Game Mode HUD(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The Player or Players who will have their Game Mode HUD enabled.
