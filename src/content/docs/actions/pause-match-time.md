---
title: "Pause Match Time"
---

## Description

Pauses the match time. Players, objective logic, and game mode advancement criteria are unaffected by the pause.
\
### Trivia
      Pausing the match time will not stop the game from closing after 4h30
			(1h30 in Practice Range).

## Snippet

```
Pause Match Time;
```
