## Description

<big>Undoes the effect of the Disable Voice Chat Action for one or more Players.</big>

## Snippet

```
Enable Voice Chat(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The Player or Players who will have their Voice Chat enabled.
