## Description

<big>Stores a value into a global variable, which is a variable that belongs to the game itself.</big>

## Snippet

```
Set Global Variable(variableName, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Variable_==, ==_Value_==

> ==**Variable**==
> _Type: **Global Variable**, Default: **A**_
> Specifies which global variable to store the value into.

> ==**Value**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The value that will be stored.
