## Description

<big>Sets the projectile gravity for one or more players to a percentage of regular projectile gravity.</big>

## Snippet

```
Set Projectile Gravity(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Projectile Gravity Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose projectile gravity will be set.

> ==**Projectile Gravity Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The percentage of regular projectile gravity to which the player or players will set their personal projectile gravity.
