---
title: "Declare Team Victory"
---

## Description

Instantly ends the match with the specified team as the winner. This action has no effect in free-for-all modes. If a team is not specified, the game will show the "DRAW" message, but play the victory sound.

## Snippet

```
Declare Team Victory(Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Team_==

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The winning team.
