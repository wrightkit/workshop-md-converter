---
title: "Declare Round Victory"
---

## Description

<big>Declare a team as the current round winner. This only works in the control and elimination game modes.</big>

## Snippet

```
Declare Round Victory(Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Round Winning Team_==

> ==**Round Winning Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> Round winning team
