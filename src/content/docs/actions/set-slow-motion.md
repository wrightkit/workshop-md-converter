## Description

<big>Sets the simulation rate for the entire game, including all players, projectiles, effects, and game mode logic.</big>

## Snippet

```
Set Slow Motion(0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Speed Percent_==

> ==**Speed Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The simulation rate as a percentage of normal speed. Only rates up to 100% are allowed.
