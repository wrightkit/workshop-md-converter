## Description

<big>Sets the movement gravity for one or more players to a percentage regular movement gravity.</big>

## Snippet

```
Set Gravity(Event Player, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==, ==_Gravity Percent_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose movement gravity will be set.

> ==**Gravity Percent**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The percentage of regular movement gravity to which the player or players will set their personal movement gravity.
