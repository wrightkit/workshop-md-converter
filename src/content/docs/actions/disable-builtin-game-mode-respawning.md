## Description

<big>Disables automatic respawning for one or more players, only allowing respawning by scripting commands.</big>

## Snippet

```
Disable Built-In Game Mode Respawning(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_PlayerS_==

> ==**PlayerS**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players whose respawning is affected.
