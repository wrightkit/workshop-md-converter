## Description

<big>Removes one or more Players from the Custom Game. This action doesn't work on Dummy Bots.</big>

## Snippet

```
Remove Player(Event Player);
```

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The Player or Players to remove.
