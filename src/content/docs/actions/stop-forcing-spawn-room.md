---
title: "Stop Forcing Spawn Room"
---

## Description

Undoes the effect of the Start Forcing Spawn Room action for the specified team.

## Snippet

```
Stop Forcing Spawn Room(Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Team_==

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team that will resume using their normal spawn room.
