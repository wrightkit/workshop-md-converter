---
title: "Destroy Progress Bar HUD Text"
---

## Description

Destroys Progress Bar HUD text that was created by Create Progress Bar HUD Text.

## Snippet

```
Destroy Progress Bar HUD Text(Last Text ID);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Text ID_==

> ==**Text ID**==
> _Type: **Text ID**, Default: **[Last Text ID](/values/last-text-id/)**_
> Specifies which Progress Bar HUD text to destroy. This ID may be Last Text ID or a Variable into which Last Text ID was earlier stored.
