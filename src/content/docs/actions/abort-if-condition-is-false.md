---
title: "Abort If Condition Is False"
---

## Description

<big>Stops execution of the action list if at least one condition in the condition list is false. If all conditions are true, execution continues with the next action.</big>

## Snippet

```
Abort If Condition Is False;
```

**Returns**: _<span style="color: #c678dd">Void</span>_
