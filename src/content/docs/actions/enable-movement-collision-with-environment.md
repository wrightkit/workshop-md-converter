---
title: "Enable Movement Collision With Environment"
---

## Description

Undoes the effect of the Disable Movement Collision With Enviroment action for one or more Players.

## Snippet

```
Enable Movement Collision With Environment(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The Player or Players whose movement collision is affected.
