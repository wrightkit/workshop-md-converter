## Description

<big>Allows one or more players to spectate all players when dead, as opposed to only allies.</big>

## Snippet

```
Enable Death Spectate All Players(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)** | **Array** (**Player**), Default: **[Event Player](/values/event-player/)**_
> The player or players who will be allowed to spectate all players.
