---
title: "Stop Assist"
---

## Description

Stops an assist that was started by the Start Assist Action.

## Snippet

```
Stop Assist(Last Assist ID);
```

## Properties

**Returns**: _<span style="color: #c678dd">Void</span>_
**Parameters**: ==_Assist ID_==

> ==**Assist ID**==
> _Type: **AssistId**, Default: **[Last Assist ID](/values/last-assist-id/)**_
> Specifies which assist instance to stop. This ID may be Last Assist ID or a Variable into which Last Assist ID was earlier stored.
