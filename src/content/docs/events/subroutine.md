---
title: "Subroutine"
---

Subroutines are a special kind of event that can be triggered manually with Call Subroutine or Start Rule. They also cannot have conditions.

A maximum of 128 subroutines can be created.

#### Argument

*  `Subroutine` - The associated name of this subroutine. A name can only be selected once in a project. These names can be edited with the `Edit Subroutine Names` button on the top right of the screen.

#### Contextual Value(s)

*  Uses the same contextual value(s) as the rule that called the subroutine.
