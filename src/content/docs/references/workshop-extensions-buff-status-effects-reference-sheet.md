Some notes:

- If an item has no "First Person" screenshot, it doesn't have an effect.
- If an item has no "Third Person" screenshot, it's either exactly the same as the regular positioned effect, or it doesn't have an effect.
- If an item has no "Friendly" it's likely a First Person only effect.
- If an item has "Friendly" but no "Enemy" both effects are the same.
