This is a list of abilities that can be detected by `Has Status`. If there is a misspelled ability name, incorrect validation, or changes to an ability, someone please update it.
The custom game used for verification can be imported with `YFPB7`.

### Notes
- Respawn areas always return true for ==Phased Out==.
- **Accretion** and **Earthshatter** return true for both ==Knocked Down== and ==Stunned==.
- **Configuration: Artillery** and **Rip Tire** return false for ==Rooted== (as players can move the enemies that use these ultimates).
- **Blizzard** returns true for ==Stunned==.
