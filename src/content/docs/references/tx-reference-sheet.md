In Overwatch, textures and icons are represented by a special code known as a \<tx> code. This article provides a list of possible \<tx> codes visible in game.

> _Note: This list does not include all \<tx> codes. \<tx> codes and screenshots were obtained from [TX Browser](https://workshop.codes/8B9H1). \<tx> codes are not in order.
\<tx> Codes are subject to change with any update to the game, so this list may not always be accurate._

These codes can be used in the Workshop, but first, you need to obtain a unsanitized bracket `<` ([TX / FG: Textures and Colors in Strings](/tutorials/tx-fg-textures-and-colors-in-strings/)). After doing that, you can use `Custom String("{0}tx CODE>", Global.bracket);`. Remember that the opening bracket needs to be omitted for it to work.
