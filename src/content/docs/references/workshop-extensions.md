---
title: "Workshop Extensions"
---

> Workshop Extensions are a system which allows users to enable certain enhancements, such as access to new effects and increasing the number of dummy bots. These enhancements can be enabled using Extension Points, which are earned by either disabling player slots, disabling all non-Workshop maps, or a combination of both.

The Extensions menu can be accesed by entering the Workshop Editor and clicking the Extensions button <img src="https://imgur.com/XlO3s5O.png" width="24" height="24" alt="Extensions button" />.

4 Extension Points are earned for each disabled player slot, and 16 are earned for leaving only Workshop maps enabled.
