title: "Is Using Ultimate"
---

## Description

<big>Whether a player is using an ultimate ability. For Echo, this value detects when the duplicated hero's ultimate is being used. To detect Duplicate itself, use [Is Duplicating](/values/is-duplicating/).</big>

## Snippet

```
Is Using Ultimate(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose ultimate ability usage to check.
