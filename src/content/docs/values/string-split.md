## Description

<big>Results in an Array of String Values. These String Values will be built from the specified String Value, split around the separator String.</big>

## Snippet

```
String Split(Global.variableName, Global.variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Array</span> (<span style="color: #c678dd">String</span>)_
**Parameters**: ==_String_==, ==_Separator_==

> ==**String**==
> _Type: **String**, Default: **[Global Variable](/values/global-variable/)**_
> The String Value to split.

> ==**Separator**==
> _Type: **String**, Default: **[Global Variable](/values/global-variable/)**_
> The separator String with which to split the String Value.
