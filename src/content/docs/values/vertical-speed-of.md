## Description

<big>The current vertical speed of a player in meters per second. This measurement excludes all horizontal motion, including motion while traveling up and down slopes.</big>

## Snippet

```
Vertical Speed Of(Event Player);
```

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose vertical speed to acquire.
