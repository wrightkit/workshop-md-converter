## Description

<big>Whether the specified objective has been completed. Results in false if the game mode is not assault, escort, or assault/escort.</big>

## Snippet

```
Is Objective Complete(0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Number_==

> ==**Number**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The index of the objective to consider, starting at 0 and counting up. Each control point, payload checkpoint, and payload destination has its own index.
