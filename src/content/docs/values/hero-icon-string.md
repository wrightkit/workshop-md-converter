## Description

<big>Converts a hero parameter into a string that shows up as an icon.</big>

## Snippet

```
Hero Icon String(Hero(Tracer));
```

**Parameters**: ==_Value_==

> ==**Value**==
> _Type: **Hero**, Default: **[Hero](/values/hero/)**_
