---
title: "Modulo"
---

## Description

<big>The remainder of the left-hand operand divided by the right-hand operand. Any number modulo zero results in zero.</big>

## Snippet

```
Modulo(0, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Value_==, ==_Value_==

> ==**Value**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The left-hand operand. May be any value that results in a number.

> ==**Value**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The right-hand operand. May be any value that results in a number.
