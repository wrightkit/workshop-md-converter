## Description

<big>Results in the Then value when the If condition is true; otherwise, results in the Else value.</big>

## Snippet

```
If-Then-Else(True, 0, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Object</span>_ | _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_If_==, ==_Then_==, ==_Else_==

> ==**If**==
> _Type: **Boolean**, Default: **[True](/values/true/)**_
> If this condition evaluates to true, the result of the value is then; otherwise, the result is else.

> ==**Then**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The result of the value when the if condition evaluates to true.

> ==**Else**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The result of the value when the if condition evaluates to false.
