---
title: "Randomized Array"
---

## Description

<big>A copy of the specified array with the values in a random order.</big>

## Snippet

```
Randomized Array(Global.variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_Array_==

> ==**Array**==
> _Type: **Array**, Default: **[Global Variable](/values/global-variable/)**_
> The array whose copy will be randomized.
