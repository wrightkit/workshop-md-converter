## Description

<big>The integer to which the specified value rounds.</big>

## Snippet

```
Round To Integer(0, UP);
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_Value_==, ==_Rounding Type_==

> ==**Value**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The real number to round.

> ==**Rounding Type**==
> _Type: **[Rounding](/constants/rounding/)**, Default: **UP**_
> Determines the direction in which the value will be rounded.
