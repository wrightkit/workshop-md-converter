---
title: "Number"
---

### Description
      A real number constant.
\
### Return
>  float


\
### Arguments


> **Name**: NUMBER
  **Description**: A real number constant.
  **Type**: float
  **Default**: 0

### Trivia
In actions/values that expect a boolean, a `Number` acts as:
* `False` if it is equal to 0.
* `True` if it is not equal to 0.
