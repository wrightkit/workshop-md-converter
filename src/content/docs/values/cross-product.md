---
title: "Cross Product"
---

## Description

<big>The cross product of the specified values. (Left cross up equals forward.)</big>

## Snippet

```
Cross Product(Vector(0, 0, 0), Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Vector</span>_
**Parameters**: ==_Value_==, ==_Value_==

> ==**Value**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The left-hand-side vector operand of the cross product.

> ==**Value**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The right-hand-side vector operand of the cross product.
