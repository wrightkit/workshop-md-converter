## Description

<big>A vector composed of three real numbers (x, y, z) where x is left, y is up, and z is forward. Vectors are used for position, direction, and velocity.</big>

## Snippet

```
Vector(0, 0, 0);
```

> The x value of the vector.

> ==**Y**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The y value of the vector.

> ==**Z**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
