## Description

Allows you to use an icon inside of a string.

==_For a visual list of all icons check out the Icon Reference Sheet_==

## Snippet

```
Icon String(Arrow: Down);
```

## Properties

**Returns**: _<span style="color: #c678dd">String</span>_
**Parameters**: ==_Icon_==

> ==**Icon**==
> _Type: **[Icon](/constants/icon/)**, Default: **Arrow: Down**_
> The icon to display.
