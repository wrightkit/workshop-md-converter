## Description

<big>The number of players playing a specific hero on a team or in the match.</big>

## Snippet

```
Number of Heroes(Hero(Tracer), Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_Hero_==, ==_Team_==

> ==**Hero**==
> _Type: **Hero**, Default: **[Hero](/values/hero/)**_
> The hero to check for play.

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team or teams on which to check for the hero being played.
