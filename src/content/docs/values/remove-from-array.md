## Description

<big>A copy of an array with one or more values removed (if found).</big>

## Snippet

```
Remove From Array(All Players(All Teams), 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_Array_==, ==_Value_==

> ==**Array**==
> _Type: **Array**, Default: **[All Players](/values/all-players/)**_
> The array from which to remove values.

> ==**Value**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The value to remove from the array (if found). If this value is itself an array, each matching element is removed.
