---
title: "Server Load Average"
---

## Description

<big>Provides a percentage representing the average CPU load of the current game instance over the last two seconds. As this number approaches or exceeds 100, it becomes increasingly likely that the instance will be shut down because it is consuming too many resources.</big>

## Snippet

```
Server Load Average;
```

**Returns**: _<span style="color: #c678dd">Float</span>_
