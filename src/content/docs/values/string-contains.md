## Description

<big>Whether the specified String contains the specified Value.</big>

## Snippet

```
String Contains(Custom String(""), Custom String(""));
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_String_==, ==_Value_==

> ==**String**==
> _Type: **String**, Default: **[Custom String](/values/custom-string/)**_
> The String in which to search for the specified Value.

> ==**Value**==
> _Type: **String**, Default: **[Custom String](/values/custom-string/)**_
> The Value for which to search.
