## Description

<big>The ability resource percent for a player associated by button.</big>

## Snippet

```
Ability Resource(Event Player, Button);
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Player_==, ==_Button_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose ability to check.

> ==**Button**==
> _Type: **[Button](/values/button/)**, Default: **Button**_
> The ability to check associated by button.
