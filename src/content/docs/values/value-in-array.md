## Description

<big>The value found at a specific element of an array. Results in 0 if the element does not exist.</big>

## Snippet

```
Value In Array(Global.variableName, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Object</span>_ | _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_Array_==, ==_Index_==

> ==**Array**==
> _Type: **Array**, Default: **[Global Variable](/values/global-variable/)**_
> The array whose element to acquire.

> ==**Index**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The index of the element to acquire.
