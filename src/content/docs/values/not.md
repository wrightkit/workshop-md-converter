## Description

<big>Whether the input is false (or equivalent to false).</big>

## Snippet

```
Not(True);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Value_==

> ==**Value**==
> _Type: **Boolean**, Default: **[True](/values/true/)**_
> When this input is false (or equivalent to false), then the not value is true. Otherwise, the not value is false.
