## Description

<big>Results in the number of characters in the String value (or 0 if the value is not a string).</big>

## Snippet

```
String Length(Global.variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_String_==

> ==**String**==
> _Type: **String**, Default: **[Global Variable](/values/global-variable/)**_
> The string value whose characters to count.
