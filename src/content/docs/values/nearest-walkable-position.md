## Description

<big>The position closest to the specified position that can be stood on and is accessible from a spawn point.</big>

## Snippet

```
Nearest Walkable Position(Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Vector</span>_
**Parameters**: ==_Position_==

> ==**Position**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The position from which to search for the nearest walkable position.
