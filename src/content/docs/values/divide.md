## Description

<big>The ratio of two numbers or vectors. A vector divided by a number will yield a scaled vector. Division by zero results in zero.</big>

## Snippet

```
Divide(0, 0);
```

> ==**Value**==
> _Type: **Float** | **Vector**, Default: **[Number](/values/number/)**_
