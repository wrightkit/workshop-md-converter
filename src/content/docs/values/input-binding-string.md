---
title: "Input Binding String"
---

## Description

<big>Converts a button parameter into a string that shows up based on the player's input bindings. This value cannot be stored in variables.</big>

## Snippet

```
Input Binding String(Button);
```

## Properties

**Returns**: _<span style="color: #c678dd">String</span>_
**Parameters**: ==_Button_==

> ==**Button**==
> _Type: **[Button](/values/button/)**, Default: **Button**_
> The button for the input binding that will be converted to a string.
