## Description

<big>Whether the specified team is currently on defense. Results in false if the game mode is not assault, escort, or assault/escort.</big>

## Snippet

```
Is Team On Defense(Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Team_==

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team whose role to check.
