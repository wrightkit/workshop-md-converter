---
title: "Count Of"
---

## Description

<big>The number of elements in the specified array.</big>

### Notes
* Returns 0 (null) for non-array types (numbers, strings, bools, etc.)

## Snippet

```
Count Of(Global.variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_Array_==

> ==**Array**==
> _Type: **Array**, Default: **[Global Variable](/values/global-variable/)**_
> The array whose elements will be counted.
