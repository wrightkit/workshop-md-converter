## Description

The active spawn points for a Team or for the match, provided as an array of entities.

## Snippet

```
Spawn Points(Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_Team_==

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The Team whose spawn points to acquire.
