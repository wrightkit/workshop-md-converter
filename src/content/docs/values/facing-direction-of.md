## Description

<big>The unit-length directional vector of a player's current facing relative to the world. This value includes both horizontal and vertical facing.</big>

## Snippet

```
Facing Direction Of(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Direction</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose facing direction to acquire.
