## Description

The currently held weapon of a player. Returns 2 for Baby Dva's gun, Torbjorn's hammer, Mercy's pistol, and Lifeweaver's thorn volley; 1 otherwise.

## Snippet

```
Weapon(Event Player);
```

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose weapon to acquire.
