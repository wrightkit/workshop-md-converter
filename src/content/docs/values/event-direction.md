## Description

The incoming direction for the event currently being processed by this rule.

			In other words, the direction pointing from the attacker/healer player/projectile towards the victim/healee player from the event of the current rule.

This works with the following events:
- Player Dealt Damage
- Player Took Damage
- Player Dealt Healing
- Player Received Healing
- Player Dealt Knockback
- Player Received Knockback
