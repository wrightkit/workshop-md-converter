---
title: "Direction From Angles"
---

## Description

<big>The unit-length direction vector corresponding to the specified angles.</big>

## Snippet

```
Direction From Angles(0, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Direction</span>_
**Parameters**: ==_Horizontal Angle_==, ==_Vectical Angle_==

> ==**Horizontal Angle**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The horizontal angle in degrees used to construct the resulting vector.

> ==**Vectical Angle**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The vertical angle in degrees used to construct the resulting vector.
> -90° points straight down, and 90° points straight up.
