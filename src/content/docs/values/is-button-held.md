## Description

<big>Whether a player is holding a specific button.</big>

## Snippet

```
Is Button Held(Event Player, Button(Primary Fire));
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Player_==, ==_Button_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose button to check.

> ==**Button**==
> _Type: **[Button](/values/button/)**, Default: **Primary Fire**_
> The button to check.
