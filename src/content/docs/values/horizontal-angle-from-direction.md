## Description

<big>The horizontal angle in degrees corresponding to the specified direction vector.</big>

## Snippet

```
Horizontal Angle From Direction(Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Direction_==

> ==**Direction**==
> _Type: **Direction**, Default: **[Vector](/values/vector/)**_
> The direction vector from which to acquire a horizontal angle in degrees. The vector is unitized before calculation begins.
