## Description

<big>Whether the specified condition evaluates to true for every value in the specified array.</big>

## Snippet

```
Is True For All(Global.variableName, True);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Array_==, ==_Condition_==

> ==**Array**==
> _Type: **Array**, Default: **[Global Variable](/values/global-variable/)**_
> The array whose values will be considered.

> ==**Condition**==
> _Type: **Boolean**, Default: **[Compare](/values/compare/)**_
> The condition that is evaluated for each element of the specified array. Use the current array element value to reference the element of the array currently being considered.
