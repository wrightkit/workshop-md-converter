## Description

<big>A random value from the specified array.</big>

## Snippet

```
Random Value In Array(Global.variableName);
```

## Properties

**Returns**: _<span style="color: #c678dd">Object</span>_ | _<span style="color: #c678dd">Array</span>_
**Parameters**: ==_Array_==

> ==**Array**==
> _Type: **Array**, Default: **[Global Variable](/values/global-variable/)**_
> The array from which to randomly take a value. If a non-array value is provided, the result is simply the provided value.
