## Description

<big>A random real number between the specified min and max.</big>

## Snippet

```
Random Real(0, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Min_==, ==_Max_==

> ==**Min**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The smallest real number allowed.

> ==**Max**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> The largest real number allowed.
