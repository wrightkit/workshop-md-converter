## Description

<big>The player farthest from a position, optionally restricted by team.</big>

## Snippet

```
Farthest Player From(Vector(0, 0, 0), Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Player</span>_
**Parameters**: ==_Center_==, ==_Team_==

> ==**Center**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The position from which to measure distance.

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team or teams from which the farthest player will come.
