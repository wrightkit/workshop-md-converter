## Description

<big>Whether an entity has spawned in the world. Results in false for players who have not chosen a hero yet.</big>

## Snippet

```
Has Spawned(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Entity_==

> ==**Entity**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player, icon entity, or effect entity whose presence in world to check.
