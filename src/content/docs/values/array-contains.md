## Description

<big>Whether the specified array contains the specified value.</big>

## Snippet

```
Array Contains(All Players(All Teams), 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Array_==, ==_Value_==

> ==**Array**==
> _Type: **Array**, Default: **[All Players](/values/all-players/)**_
> The array in which to search for the specified value.

> ==**Value**==
> _Type: **Object**, Default: **[Number](/values/number/)**_
> The value for which to search.
