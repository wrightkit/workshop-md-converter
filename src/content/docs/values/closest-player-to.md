---
title: "Closest Player To"
---

## Description

<big>The player closest to a position, optionally restricted by team.</big>

## Snippet

```
Closest Player To(Vector(0, 0, 0), Team(Team 1));
```

## Properties

**Returns**: _<span style="color: #c678dd">Player</span>_
**Parameters**: ==_Center_==, ==_Team_==

> ==**Center**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The position from which to measure proximity.

> ==**Team**==
> _Type: **[Team](/constants/team/)**, Default: **Team**_
> The team or teams from which the closest player will come.
