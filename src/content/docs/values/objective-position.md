---
title: "Objective Position"
---

## Description

<big>The position in the world of the specified objective (either a control point, a payload checkpoint, or a payload destination). Valid in assault, assault/escort, escort, and control.</big>

## Snippet

```
Objective Position(0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_Number_==

> ==**Number**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The index of the objective to consider, starting at 0 and counting up. Each control point, payload checkpoint, and payload destination has its own index.
