---
title: "Vertical Facing Angle Of"
---

## Description

<big>The vertical angle in degrees of a player's current facing relative to the world. This value increases as the player looks down.</big>

## Snippet

```
Vertical Facing Angle Of(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose vertical facing angle to acquire.
