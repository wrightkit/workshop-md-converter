## Description

<big>The current speed of a player in a specific direction in meters per second.</big>

## Snippet

```
Speed Of In Direction(Event Player, Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Player_==, ==_Direction_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose speed to acquire.

> ==**Direction**==
> _Type: **Direction**, Default: **[Vector](/values/vector/)**_
> The direction of travel in which to measure the player's speed.
