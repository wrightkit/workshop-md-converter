## Description

<big>The displacement vector from one position to another.</big>

## Snippet

```
Vector Towards(Vector(0, 0, 0), Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Direction</span>_
**Parameters**: ==_Start Pos_==, ==_End Pos_==

> ==**Start Pos**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The position from which the resulting displacement vector begins.

> ==**End Pos**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The position at which the resulting displacement vector ends.
