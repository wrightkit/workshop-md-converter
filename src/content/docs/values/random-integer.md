## Description

<big>A random integer between the specified min and max, inclusive.</big>

## Snippet

```
Random Integer(0, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Integer</span>_
**Parameters**: ==_Min_==, ==_Max_==

> ==**Min**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The smallest integer allowed. If a real number is provided to this input, it is rounded to the nearest integer.

> ==**Max**==
> _Type: **Integer**, Default: **[Number](/values/number/)**_
> The largest integer allowed. If a real number is provided to this input, it is rounded to the nearest integer.
