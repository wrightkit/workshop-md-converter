---
title: "Ability Icon String"
---

## Description

==_For a visual list of all ability icons check out the Icon Reference Sheet_==



      Converts a Hero and Button parameter into a string that shows up as an icon (up to 4 per string).

## Snippet

```
Ability Icon String(Hero(Tracer), Button);
```

## Properties

**Returns**: _<span style="color: #c678dd">String</span>_
**Parameters**: ==_Hero_==, ==_Button_==

> ==**Hero**==
> _Type: **Hero**, Default: **[Hero](/values/hero/)**_
> The hero for the ability that will be converted to an icon.

> ==**Button**==
> _Type: **Button**, Default: **Button**_
> The button for the ability that will be converted to an icon.
