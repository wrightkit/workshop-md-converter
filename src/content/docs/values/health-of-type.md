## Description

<big>The current health of the specified player, filtered by the given health type.</big>

## Snippet

```
Health Of Type(Event Player, Health);
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Player_==, ==_Health_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose health to acquire.

> ==**Health**==
> _Type: **[Health](/constants/health/)**, Default: **Health**_
> The type of health to acquire.
