## Description

<big>Arctangent in degrees of the specified numerator and denominator (often referred to as atan2).</big>

## Snippet

```
Arctangent In Degrees(0, 0);
```

> _Type: **Float**, Default: **[Number](/values/number/)**_

> ==**Denominator**==
> _Type: **Float**, Default: **[Number](/values/number/)**_
> Denominator input for the function.
