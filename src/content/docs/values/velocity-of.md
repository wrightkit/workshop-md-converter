## Description

<big>The current velocity of a player as a vector. If the player is on a surface, the y component of this velocity will be 0, even when traveling up or down a slope.</big>

## Snippet

```
Velocity Of(Event Player);
```

## Properties

**Returns**: _<span style="color: #c678dd">Velocity</span>_
**Parameters**: ==_Player_==

> ==**Player**==
> _Type: **[Player](/constants/player/)**, Default: **[Event Player](/values/event-player/)**_
> The player whose velocity to acquire.
