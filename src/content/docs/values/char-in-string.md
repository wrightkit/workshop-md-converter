---
title: "Char In String"
---

## Description

<big>The character found at a specified index of a String.</big>

## Snippet

```
Char In String(Global.variableName, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">String</span>_
**Parameters**: ==_String_==, ==_Index_==

> ==**String**==
> _Type: **String**, Default: **[Global Variable](/values/global-variable/)**_
> The String Value whose character to acquire.

> ==**Index**==
> _Type: **Integer**, Default: **0**_
> The index of the character to be acquired (with 0 as the first character, 1 as the second character, etc.). If this index is outside the bounds of the string, an empty string will be returned instead.
