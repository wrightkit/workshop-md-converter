## Description

<big>Whether the comparison of the two inputs is true.</big>

## Snippet

```
Compare(0, ==, 0);
```

## Properties

**Returns**: _<span style="color: #c678dd">Boolean</span>_
**Parameters**: ==_Value_==, ==_Comparison_==, ==_Value_==

> ==**Value**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The left-hand side of the comparison. This may be any value type if the operation is == or !=. Otherwise, real numbers are expected.

> ==**Comparison**==
> _Type: **[Operator](/constants/operator/)**, Default: **==**_
>

> ==**Value**==
> _Type: **Object** | **Array**, Default: **[Number](/values/number/)**_
> The right-hand side of the comparison. This may be any value type if the operation is == or !=. Otherwise, real numbers are expected.
