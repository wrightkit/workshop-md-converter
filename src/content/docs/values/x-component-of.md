## Description

<big>The x component of the specified vector, usually representing a leftward amount.</big>

## Snippet

```
X Component Of(Vector(0, 0, 0));
```

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Value_==

> ==**Value**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The vector from which to acquire the x component.
