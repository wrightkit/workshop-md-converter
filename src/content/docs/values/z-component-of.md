## Description

<big>The z component of the specified vector, usually representing a forward amount.</big>

## Snippet

```
Z Component Of(Vector(0, 0, 0));
```

## Properties

**Returns**: _<span style="color: #c678dd">Float</span>_
**Parameters**: ==_Value_==

> ==**Value**==
> _Type: **Position**, Default: **[Vector](/values/vector/)**_
> The vector from which to acquire the z component.
