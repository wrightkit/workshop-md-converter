# Importing a Custom Game Code

**1: Create a Custom Game**
*Play > Custom Games > Create*
![](https://cdn.workshop.codes/7ksjvvsq77vr1d27hl5p14o8yspt)

**2: Go to settings**
![](https://cdn.workshop.codes/9n3a041ejtbnkv7v5mda8uc1kb0d)

**3: Click "Import Code"**
![](https://cdn.workshop.codes/c6ce9z4jwv5yqxiyu2jy4cplys6e)

**4: Insert the Code and click OK**
![](https://cdn.workshop.codes/h7jwvgwsdcogqez1a91g6ra6dawo)

After the code has loaded, you can start playing the game!
