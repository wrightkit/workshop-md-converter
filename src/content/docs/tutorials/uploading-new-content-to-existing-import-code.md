# Instructions:
1. From the custom game lobby screen, press __Settings__ in the top right.
![The location of the Settings button](https://i.imgur.com/a87JFi6.png)
2. Press the __Share__ button in the top right of the Settings screen.
![The location of the Share button](https://i.imgur.com/XJxahbw.png)
3. Press the dropdown and select `Upload to Existing Code`.
![The dropdown presented upon pressing the Share button](https://i.imgur.com/e0e9Bez.png)
4. Fill in the import code you would like to upload to (in this case, `Q74P7`), and press Continue.
![Filling in the import code](https://i.imgur.com/xFNljPt.png)
5. Wait for the code to be updated, and then copy the code if needed.
![](https://i.imgur.com/eajBeRn.png)
