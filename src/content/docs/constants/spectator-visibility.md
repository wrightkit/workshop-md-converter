---
title: "Spectator Visibility"
---

## Description
Used in [Create In-World Text](/actions/create-inworld-text/), [Create Progress Bar In-World Text](/actions/create-progress-bar-inworld-text/), [Create HUD Text](/actions/create-hud-text/) and [Create Progress Bar HUD Text](/actions/create-progress-bar-hud-text/). Whether non-team spectators can see the text or not.

## Options
- **Default Visibility**
  - Non-team spectators can see text when all players can see it.
- **Visible Always**
  - Non-team spectators can always see text.
- **Visible Never**
  - Non-team spectators can never see text.
