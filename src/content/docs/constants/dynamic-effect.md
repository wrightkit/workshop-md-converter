## Description

Used in [Play Effect](/actions/play-effect/). The type of effect to be created.

## Options
- **Bad Explosion**
- **Bad Pickup Effect**
- **Buff Explosion Sound**
- **Buff Impact Sound**
- **Debuff Impact Sound**
- **Explosion Sound**
- **Good Explosion**
- **Good Pickup Effect**
- **Ring Explosion**
- **Ring Explosion Sound**
