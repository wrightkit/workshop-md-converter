---
title: "Async Behavior"
---

### Description
Used in [Start Rule](/actions/start-rule/). Determines what should happen if the rule specified by the subroutine is already executing on the same player or global entity.

### Options
- **Restart Rule**
  - Restart the specified rule with new contextual values (including event player, attacker, victim, etc).
- **Do Nothing**
  - Allow the rule to finish executing without changing its contextual values.
