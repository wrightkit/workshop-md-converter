---
title: "Healing Reevaluation"
---

## Description

Used in [Start Healing Modification](/actions/start-healing-modification/). Specifies which of the action's inputs will be continuously reevaluated. The action will keep asking for and using new values from reevaluated inputs.

## Options
- **None**
- **Receivers and Healers**
- **Receivers Healers and Healing Percent**
