title: "Chase Rate Reevaluation"
---

## Description

Used in [Chase Global Variable At Rate](/actions/chase-global-variable-at-rate/) and [Chase Player Variable At Rate](/actions/chase-player-variable-at-rate/). Specifies which of the action's inputs will be continuously reevaluated. The action will keep asking for and using new values from reevaluated inputs.

## Options
- **Destination and Rate**
- **None**
