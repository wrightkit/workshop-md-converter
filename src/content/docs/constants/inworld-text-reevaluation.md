---
title: "In-World Text Reevaluation"
---

## Description
Used in [Create In-World Text](/actions/create-inworld-text/). Specifies which of this action's inputs will be constantly reevaluated. The text will keep asking for and using new values from reevaluated inputs.

## Options
- **Color**
- **None**
- **String**
- **String and Color**
- **Visible To**
- **Visible To and Color**
- **Visible To and Position**
- **Visible To and String**
- **Visible To, Position and Color**
- **Visible To, Position and String**
- **Visible To, Position, String and Color**
- **Visible To, String and Color**
