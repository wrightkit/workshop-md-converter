## Description
Used in [Modify Global Variable](/actions/modify-global-variable/), [Modify Player Variable](/actions/modify-player-variable/), [Modify Global Variable At Index](/actions/modify-global-variable-at-index/) and [Modify Player Variable At Index](/actions/modify-player-variable-at-index/). The way in which the variable's value will be changed. Options include standard arithmetic operations as well as array operations for appending and removing values.

## Options
- **Add**
- **Append To Array**
- **Divide**
- **Max**
- **Min**
- **Modulo**
- **Multiply**
- **Raise To Power**
- **Remove From Array By Index**
- **Remove From Array By Value**
- **Subtract**
