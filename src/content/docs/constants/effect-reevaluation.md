---
title: "Effect Reevaluation"
---

## Description
Used in[ Create Effect](/actions/create-effect/). Specifies which of this action's inputs will be constantly reevaluated. The effect will keep asking for and using new values from reevaluated inputs.

## Options
- **Color**
- **None**
- **Position and Radius**
- **Position Radius and Color**
- **Visible To**
- **Visible To And Color**
- **Visible To Position and Radius**
- **Visible  To Position Radius and Color**
