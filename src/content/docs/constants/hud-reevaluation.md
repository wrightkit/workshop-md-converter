## Description

Used in [Create HUD Text](/actions/create-hud-text/). Specifies which of this action's inputs will be continuously reevaluated.

- **Sort Order and String**
- **Sort Order, String and Color**
- **String**
- **String and Color**
- **Visible To**

- **Visible To and Sort Order**
- **Visible To and String**
- **Visible To, Sort Order and Color**
- **Visible To Sort Order and String**
- **Visible To, Sort Order, String and Color**
- **Visible To, String and Color**
