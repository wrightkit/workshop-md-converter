title: "Chase Time Reevaluation"
---

## Description

Used in [Chase Global Variable Over Time](/actions/chase-global-variable-over-time/) and [Chase Player Variable Over Time](/actions/chase-player-variable-over-time/). Specifies which of the action's inputs will be continuously reevaluated. The action will keep asking for and using new values from reevaluated inputs.

## Options
- **Destination and Duration**
- **None**
